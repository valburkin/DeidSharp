# Changelog

All notable changes to DeidSharp are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/): a change that breaks the public API comes with a new major version, and is listed under "Changed" or "Removed".

## [Unreleased]

## [1.1.0] - 2026-10-30

### Added

- **Guide** ([docs/guide.md](docs/guide.md)): how to install, choose a detector stack, de-identify free text and FHIR, add the clinical sidecar or a local language model, pseudonymize, check output, handle errors, run DeidSharp in a service, read its telemetry and measure it on your own data, with a reference of every option. Its examples run as tests (`GuideExamplesTests`).
- **Samples** ([samples](samples)): three console programs (free text, a FHIR bundle, a local language model), built by CI.
- **Evaluation on MIMIC-IV-Note**: `--corpus mimic-iv-note` builds a corpus of 1,000 MIMIC-IV-Note 2.2 discharge summaries (one per patient, a fixed hashed sample) whose `___` placeholders are filled with made-up surrogates that become the gold spans, typed by context rules; `--gold-review` writes the gold spans in context for a person to check ([evaluation](docs/evaluation/README.md#mimic-iv-note-with-surrogates)). Its reporting half, measured once under a protocol fixed beforehand, is in the [results](docs/evaluation/README.md#results) and [findings](docs/evaluation/findings.md) (F41).
- **Miss profile**: the evaluation tool's `--miss-profile <label>` counts each stack's misses of one corpus label by feature (one word, an ordinary word, found elsewhere in the note), printing counts only; `--variants` now also wraps the stacks with a language model ([findings](docs/evaluation/findings.md), F42).
- **Model baselines**: `tools/baselines/models` builds one offline image that runs the Stanford/Penn de-identifier, OpenAI Privacy Filter and GLiNER multi-PII, each at its defaults with its weights pinned by commit, on an NVIDIA GPU, on an `--export` of a corpus, and writes their spans for `--predictions` ([evaluation](docs/evaluation/README.md#comparing-with-model-baselines)).
- **Language-model stacks in the published results**: the evaluation tool's `--publish` now takes `--llm` (with `--llm-prompts`, `--gazetteer with,without`, `--clinical-places` and the second opinion), and records Ollama's version and each model's digest with the results, read before the run and checked after it; the README's badge shows the recall-first stack beside the one without a model ([evaluation](docs/evaluation/README.md#results)).
- **Out-of-scope check**: the evaluation tool's `--out-of-scope neutral` leaves out the predictions that touch only gold outside the scope (a bare year, an age under 90), so tagging them counts neither for nor against a tool; a sensitivity check, never published ([findings](docs/evaluation/findings.md), F47).
- **Strict span match**: `EvaluationReport.Strict` gives recall, precision and F1 counting only predictions with exactly a gold span's start and end, categories aside, like the binary evaluation of the 2014 i2b2/UTHealth challenge; the evaluation tool shows it on the console and publishes it in `results.json`.

### Changed

- `PhiDetectionException.InnerException` is now null when a detector throws (and when the Presidio detector's response isn't a result list, or a handler in its HTTP pipeline fails): the message names the original exception's type instead. Code that inspected the inner exception should read the message, or the Presidio detector's `HttpRequestException`, which is still passed on. See Security below.
- A release no longer measures the evaluation again when its changes can't alter what the measured stacks find: published results keep the version and commit they were measured at. CI refuses a release tag when the results on the nursing notes (PhysioNet's Deidentified Medical Text) or ASQ-PHI are missing, or when any published result comes from a later version or from code that has changed since, unless the findings record why it still stands ([evaluation](docs/evaluation/README.md#before-a-release), D5).
- The README starts from what a user needs (install, quick start, which stack), and the evaluation README opens with the results at a glance, language-model stacks included.
- The published results come from one run of record per corpus at version 1.1.0, under a protocol fixed beforehand: the stacks with and without a language model, deid, Philter and the three model baselines, scored together ([findings](docs/evaluation/findings.md), D6 and F46). The guide's numbers follow it; three stacks move by at most 0.3 points. Stock Presidio, no recommended stack, left the published tables; its numbers stand in the findings (F37, F39, F41).
- [safe-harbor.md](docs/safe-harbor.md) lists a gap that was undocumented: in free text, the birth year of someone aged 90 or over is kept, since a date is cut to its year without knowing whose it is (FHIR removes the record's birth date).
- The [guide](docs/guide.md#the-recommended-stacks) and the [threat model](docs/threat-model.md) warn that `LlmSecondOpinion` sends the whole note at once, so the model server's context window must fit the longest note; Ollama cuts a longer prompt from the start, instructions included, without an error.
- Dependencies: `DeidSharp.Fhir` requires Hl7.Fhir.R4 6.8.0 and `DeidSharp.Llm` requires Microsoft.Extensions.AI.Abstractions 10.11.0.

### Fixed

- The clinical sidecar no longer returns an empty span when its model tags a token made only of spaces, which made DeidSharp's Presidio detector fail closed on texts with long runs of spaces (form-like headers in discharge summaries). Spans that cover only whitespace are dropped; they hide nothing.

### Security

- `PhiDetectionException` no longer passes on a detector's exception as its inner exception, since some exceptions hold the text they were working on in a property (a regex timeout's `Input`) that a structured logger writes out; its message names the exception's type instead ("Detector 'patterns' failed with RegexMatchTimeoutException.").
- The clinical sidecar's images take certifi 2026.10.23, filelock 4.2.4 and setuptools 84.2.1, which fix known vulnerabilities.

## [1.0.0] - 2026-10-19

The first public release.

### Added

- **Libraries** (`DeidSharp`, `DeidSharp.Fhir`, `DeidSharp.Presidio`): HIPAA Safe Harbor transforms, keyed HMAC pseudonyms and per-patient date shifts, stackable PHI detectors for free text (the record's known identifiers, a pattern library, Presidio), tag or surrogate replacement, a deterministic leak guard, re-identification risk metrics and detector evaluation. FHIR R4 resources and bundles are de-identified by a rule chain and verified before they are returned.
- **Clinical sidecar**: Presidio with the `obi/deid_roberta_i2b2` model on transformers 5, running offline, without three of Presidio's recognizers that flagged far more clinical text than PHI (spaCy's general NER, URLs and US driver's licenses: on PhysioNet's notes, precision from 5% to 55% for 2 points of recall; `DEIDSHARP_KEEP_RECOGNIZERS` keeps any of them), built from a hash-locked set of packages. A GPU build (`DEVICE=cuda`, compose profile `gpu`) runs the same model on CUDA PyTorch from its own lock, and refuses to start without a GPU.
- **Scaling**: known identifiers are found through an anchor index, so a bundle's thousands of identifiers cost a scan per text instead of a search each; a bundle's free text is de-identified concurrently (`MaxFreeTextConcurrency`).
- **Recognizer sources**: `PresidioOptions.ReportRecognizers` records which of the analyzer's recognizers found a span in its source ("clinical:SpacyRecognizer"); the clinical sidecar returns the recognizer's name.
- **Gazetteer** (`DeidSharp.Gazetteer`): a deterministic detector for names and places from public-domain lists (US Census 2010 surnames, 1990 first names and 2024 places), with a hand-written list of clinical terms that are also names ("Foley") and context rules for names that are common words. On PhysioNet's nursing notes it raised the clinical stack's recall from 87.7% to 90.5% and lowered precision from 55% to 42%; on ASQ-PHI it raised the deterministic detectors' recall from 47.6% to 86.6%. Part of the recommended stack without a language model; the evaluation tool measures it as part of the deterministic layer. The leak guard doesn't use it. `tools/gazetteer/build.cs` regenerates the lists.
- **LLM detector** (`DeidSharp.Llm`): `LlmPhiDetector` asks a language model, through Microsoft.Extensions.AI's `IChatClient`, to list the PHI in a text, and locates each piece it lists (anything not in the text is dropped). Long texts go in overlapping pieces, and a piece whose answer is cut off at the output limit is asked again in halves; an answer that isn't the JSON asked for fails closed without being quoted. `LlmPrompt.WithExamples` adds four fictional notes and their answers (`LlmPrompt.Focused`, a stricter prompt, trades recall for precision), and `SafeHarborOnly` (default on) drops what Safe Harbor keeps from the answer: ages under 90, years and times on their own, dates with no number or month, and identifiers of three digits or fewer. On PhysioNet's held-out nursing notes, `gemma4:26b-a4b` with `LlmPrompt.WithPoolExamples` gives three measured stacks: recall first (with the clinical sidecar) 98.9% recall at 54.3% precision, balanced (with the second opinion) 98.2% at 70.8%, and precision first (no sidecar) 96.4% at 83.3%; [providers](docs/providers.md#with-a-local-language-model) shows how to build each ([findings](docs/evaluation/findings.md), F30). Meant for a local model; not part of the leak guard. The evaluation tool measures it with `--llm <ollama model>` and `--llm-prompts`.
- **Category filter**: `CategoryFilter` keeps only some categories of a detector's spans (for example only a clinical model's `location` and `organization` spans next to a language model); the evaluation tool measures it with `--clinical-places on`.
- **Safe Harbor ages**: `SafeHarborAgeFilter` leaves out the ages under 90 a detector stack reports (NER models report every age); the evaluation tool measures every stack with it.
- **Example pool** (`DeidSharp.Llm`): `LlmExamplePool.Default` holds forty fictional annotated notes in several styles, twelve with no PHI. `LlmPrompt.WithPoolExamples` puts the whole pool in every prompt, the most precise preset measured; the model's context window must be at least 8,192 tokens. `LlmDetectorOptions.Retriever` takes an `IExampleRetriever` that picks examples for each piece of text instead; the libraries ship none, and the evaluation tool holds the TF-IDF retriever it measured (`--llm-prompts retrieved`, [findings](docs/evaluation/findings.md), F27).
- **LLM second opinion** (`DeidSharp.Llm`): `LlmSecondOpinion` shows a language model the spans only noisier detectors found and drops those it calls not PHI; it trades recall for precision, so it is opt-in. The evaluation tool measures it with `--llm-second-opinion on`, and `--gazetteer with,without` measures stacks without the gazetteer.
- **Several Presidio services in one stack**: `AddPresidioDetector(name, …)` registers each as a keyed service with its own options and HTTP client.
- **Local only**: every service in `docker-compose.yml` is published on 127.0.0.1 only.
- **Telemetry**: a `DeidSharp` meter and activity source (detector durations by outcome, replacements by category, refused outputs) that never carry text.
- **Evaluation**: `tools/DeidSharp.Evaluation.Cli` measures the detector stacks on PhysioNet's nursing-note gold standard and on ASQ-PHI, and publishes the numbers to `docs/evaluation` with a README badge. Missed spans and false positives go to local files for review, never into the repository. PhysioNet's notes split by patient into a tuning half and a reporting half; the badge comes from the reporting half. `--drop-sources` measures a stack without the named recognizers, to see what each adds before a sidecar changes, and `--variants` measures each stack with a change, such as `repeated-names` (the tool's `RepeatedNameDetector`, which finds the other mentions of the names a stack found; it added almost nothing, F7), with the change's paired confidence interval. `--predictions` scores other tools from files of their spans with the same scorer, including PhysioNet deid's own `.phi` output (deid itself is not included; you run it yourself); scored this way, deid's output matches the recall and precision in its paper. Results carry word-level precision, recall and F1, the share of non-PHI text removed, and 95% confidence intervals from a bootstrap by patient; the library's `DetectionEvaluator` reports the same numbers, and its per-document `EvaluationTally` adds up, for resampling. CI holds every build to recall floors on ASQ-PHI and refuses a release tag whose results came from another version. [REPRODUCING.md](REPRODUCING.md) gives the environment and the commands behind every measurement. The results of record were measured at 1.0.0, with deid and Philter paired against every stack ([findings](docs/evaluation/findings.md), F36 to F39).
- **Baselines**: the evaluation tool compares every stack with another tool's spans on the same resamples (`--compare-with`), and writes a corpus out for other tools to read (`--export`). `tools/baselines` runs Philter (philter-ucsf 1.0.3) in a pinned image and converts deid's and Philter's output to the tool's span format, so both are scored by the same code as DeidSharp ([evaluation](docs/evaluation/README.md#comparing-with-philter)).
- **Packages**: the five libraries on nuget.org, with an icon, symbol packages and Source Link, so a debugger steps into the sources of the packed commit. CI packs and publishes them from a release tag by Trusted Publishing, so no API key is stored.
- **Project**: CI on Linux and Windows, CodeQL, Dependabot, a security policy and contribution guidelines.
