# Code of conduct

DeidSharp follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in the project, in issues, pull requests, discussions and reviews, is expected to follow it: be respectful, assume good faith, and keep criticism about the work.

To report unacceptable behavior, use the private reporting form on the repository's **Security** tab (**Report a vulnerability**) and start the title with "Code of conduct". Only the maintainer sees it, and it is handled confidentially. GitHub's own **Report content** option is there too, for content that breaks GitHub's terms.

One rule specific to this project: never post real patient data anywhere in it, even to illustrate a problem. Such content is deleted, edit history included.
